Skuggerelieff-figurar

Stad

Desimalgrader (breidd, lengd), grader-minutt-sekund, eller UTM «sone austing nording» (UTM33 = SWEREF99 TM, UTM35 = TM35FIN).

Kartoppsett

0 %
0 % = reint skuggerelieff. Høgare verdi = meir av det vanlege kartet oppå (hybrid).
«Felles» brukar same topografiske kart i Noreg, Sverige og Finland, så figurar frå ulike land ser like ut.
Maks detalj hentar 2–9 MB høgdedata per flis, så eit nytt utsnitt tek nokre sekund. Eksporten brukar dei same flisene som skjermen.
1.00
Z-faktor for det finske relieffet: 0,5 ≈ mjukt som Kartverket, 1 = normalt, 1,5–2 = markant (som i finske kart), så relieffet held seg tydeleg under eit kraftig hybridkart. Blir lagra med figuren. Verkar berre med MML-nøkkel.

Du kan òg rotera ved å halda inne Ctrl og dra i kartet. Rotasjonen blir med i eksporten.

Vatn

Nasjonalt vatn hentar vassflater og elvar frå det same kartet som norgeskart.no – rette linjer og rett blåfarge. Sverige og Finland har ikkje eit ope vatn-lag, så dei brukar OpenStreetMap uansett.

Markørar

Legg til markørar ved å klikka i kartet eller med «Gå til». Dra ein markør for å flytta han.

Eksport

«Som på skjermen» gjev ei fil som er nøyaktig lik førehandsvisinga, berre i høgare oppløysing. Dei andre vala hentar finare kartfliser – då blir teksten i kartet mindre i høve til utsnittet.

Lagra figurar

Avansert
Noreg og Sverige treng ingen oppsett – alt blir henta frå opne tenester hos Kartverket og Lantmäteriet.
Med nøkkel blir det finske skuggerelieffet rekna frå Maanmittauslaitos sin 2 m-høgdemodell (like skarpt som Kartverket/Lantmäteriet, med same grå grunntone), og i hybrid blir bakgrunnskartet MML sitt eige kart (maastokartta) når «Bakgrunnskart» står på Nasjonalt. Over grensa til Noreg/Sverige blir høgdene fylte inn frå den globale høgdemodellen. Utan nøkkel: global høgdemodell (EU-DEM) og OpenTopoMap.
Gratis nøkkel: registrer deg på omatili.maanmittauslaitos.fi og opprett ein nøkkel for «avoimet rajapintapalvelut».
